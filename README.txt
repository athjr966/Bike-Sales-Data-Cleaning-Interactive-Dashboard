Bike Sales Data Cleaning & Dashboard Project

Overview:
This project focuses on cleaning and analysing raw sales data to make it usable for reporting. 
The dataset contained duplicates and inconsistent formatting.

Dataset:
- Raw data provided in a separate file

Data Cleaning Process:
- Removed duplicate records
- Standardised formats (e.g., text)
- Cleaned text data

Analysis & Dashboard:
- Used Pivot Tables to summarise sales data
- Calculated average income per purchase
- Analysed the relationship between customer commute distance and purchasing behaviour
- Segmented customers into age brackets to identify demographic trends
- Created charts to visualise key insights

Tools Used:
- Microsoft Excel (Pivot Tables, charts, basic formulas)

Files Included:
- Bike Raw Dataset.xlsx
- Bike Cleaned Data & Dashboard.xlsx
